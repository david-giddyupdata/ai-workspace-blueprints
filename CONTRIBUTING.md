# Contributing

Thanks for looking. This repository documents how one person works, so it changes when my practice changes.

- **Issues are welcome:** questions, broken links, errors, and things that didn't work for you, including a setup
  that went wrong with `START_HERE.md`. Say which file, which agent tool you used, and what you expected. Opening an
  issue needs a free GitHub account.
- **Pull requests are not accepted for now.** I may close them without merging. To suggest a change, open an issue;
  to build on the work, download or fork it and adapt it under the license.
- **Never paste keys, passwords, account numbers or personal details into an issue.** Report anything sensitive
  through `SECURITY.md`.
- Be kind and specific.
